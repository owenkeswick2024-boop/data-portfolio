# 数据分析作品集

数据分析与办公自动化项目。

| 项目 | 内容 | 技术 |
|---|---|---|
| [01 零售企业销售数据分析](01-sales-analysis/) | 8,399 条订单数据的清洗与分析，定位亏损品类、折扣影响和区域差异，给出经营建议 | Pandas · Matplotlib · Jupyter |
| [02 多门店 Excel 报表一键合并汇总](02-excel-automation/) | 自动清洗 9 个格式混乱的门店报表，输出带公式和图表的汇总表 | Pandas · openpyxl |

- 数据分析报告与可视化
- BI 看板搭建
